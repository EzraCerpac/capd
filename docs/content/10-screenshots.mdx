These examples come from the fork's current views. The Mac images are windowless
renders with injected synthetic data and temporary preferences. The phone images
come from the actual app and share extension in an isolated iPhone simulator.

They contain no personal library, configured server, device credential or fetched
website asset. They demonstrate the interface, rather than a deployed connection.
[Source and image hashes](/fork/provenance.json) identify the captures.

## Mac search

![Mac search results with synthetic links, text and image metadata](/fork/mac-search.png)

The example uses local fixture icons. Search and ratings use the actual view and
model; the display does not prove website fetching or icon delivery.

## Mac settings

![Mac settings with website icon generation off](/fork/mac-settings.png)

**Load website icons** starts off. Enabling it authorizes this Mac's Agent to
generate icons for eligible links, including links from connected devices.
See [settings](/app#settings) and [connection requirements](/sync).
