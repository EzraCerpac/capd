## Permissions

### Why does Capd need Accessibility access?

Accessibility lets Capd read selected text, detect secure fields, and read the
current tab in Firefox-based browsers. It is optional. Without it, hotkey
capture falls back to content already on the clipboard; CLI capture and search
continue to work.

### Capd stopped seeing my selection after an update

macOS can revoke Accessibility when an app's code signature changes. Open
System Settings → Privacy & Security → Accessibility, remove the existing Capd
entry, and add the app again. `capd doctor` reports Accessibility for its CLI
process; that result can differ from the menu-bar app's permission.

### Why does macOS ask about Safari, Chrome, and Arc separately?

Those browsers share their current tab through Automation, and macOS stores
permission per app. Declining one browser means Capd cannot capture its current
URL or rendered page, but other capture methods still work.

Firefox, Zen, LibreWolf, Waterfox, and Search use Accessibility for their
current tab, so they do not need this Automation permission.

## Capturing

### Why was a capture blocked?

Secure input was active, usually because a password field was focused or a
password manager had enabled the system secure-input flag. Capd deliberately
reads and stores nothing in that state. Leave the secure field and try again.

### Why is page content missing or marked thin?

The fetch may have timed out, exceeded 10 MB, or reached a page that requires a
login. Very short responses are marked thin rather than treated as full
articles. The URL, title, selection, and note remain searchable.

Capturing a page from Safari, Chrome, or Arc can preserve content already
rendered in your signed-in browser. You can also retry with `capd refetch`.

### Can I capture a screenshot region?

Capd does not include a screenshot tool. Press **⌃⇧⌘4** to copy a macOS region
screenshot to the clipboard, then press **⌃⌥C**. You can also drag an existing
image file to the notch or menu-bar icon.

### What happens when I capture the same thing twice?

Capd updates the existing capture's timestamp and seen count. It does not create
a duplicate. Common tracking parameters and URL fragments are ignored during
matching.

## Data

### Where is my library, and how do I back it up?

The Mac's default location is `~/Library/Application Support/capd/`. Retain a
consistent database and the complete assets/configuration while writers are
stopped. The phone library is in its App Group; **Device sync → Prepare device
connection** retains a backup before activation. `capd export` exports capture
fields, not image/icon bytes, sync history, or Keychain credentials. See the
[sync guide](/sync) before moving or restoring an enrolled library.

### Can I import bookmarks?

Use **Import from Pinboard…** in the Mac menu or run:

```sh
capd import pinboard pinboard_export.json
```

Pinboard imports retain titles, notes, tags, and timestamps. A plain list of
URLs can also be captured in bulk:

```sh
cat urls.txt | capd add -
```

Each URL becomes its own deduplicated, searchable capture.

## Sync and iPhone

### Does this fork sync between devices?

Yes, after explicit enrollment in an authorized HTTPS library. Unconfigured
libraries remain local. This fork includes Mac and iPhone clients and a server
implementation, but does not provide a hosted service or create device access
from the app. Start with [library sync](/sync), including backup, import review,
and separate device authorization.

### Does sharing to the iPhone app deliver immediately to my Mac?

The share extension saves locally, including while the main app is closed. The
main phone app delivers those changes when active or reopened. iOS can suspend
the app, so background delivery is not guaranteed. A source marked **Available
on this device** is locally saved; that label does not prove another device or
the server has received it.

### What does the iPhone app capture?

Links and text, with optional titles and notes. Tap **Capture** or share from
another app, review the source, then choose **Save**. It does not fetch webpages,
perform OCR, or create image captures. It can display page text, recognized
image text, and generated tags received from the library. Details support
manual note/tag edits, note resolution, deletion, and sharing a URL or text.

### What happens to conflicting notes?

Saved note versions are retained for review. On Mac, choose **Review conflicting
notes…** from the menu. On iPhone, open the source's **Edit** form, review **Notes
to resolve**, and explicitly choose **Use this note to resolve all variants**
before **Save changes**. A newer version can require another review.

### Are local saves the same as accepted changes?

No. Local edits commit immediately and remain available offline; server delivery
and acceptance happen separately. Connection failures and rejected operations
retain local data. Use `capd sync status` on Mac or **Device sync** on iPhone to
inspect the state. See [troubleshooting](/troubleshooting).

## Icons and local intelligence

### Why does a link show a symbol instead of its website icon?

Mac **Load website icons** starts off. Enable it and keep the background agent
available to generate icons for eligible HTTPS links. Phone **Show synced website
icons** controls display only and starts on. New icons from either device require
the Mac Agent and, for delivery, a compatible connected server. Unsupported
hosts, missing icons, unavailable assets, and refused responses use a symbol;
the capture remains usable. See [website icon privacy](/privacy#website-icons)
and [troubleshooting](/troubleshooting).

### Why is Ask Cap unavailable or unable to answer?

It requires eligible hardware and enabled, ready Apple Intelligence. Phone Ask
Cap additionally requires iOS 26 or later and a supported locale; the rest of
the phone app supports iOS 17 or later. There is no remote fallback. The model
can also fail to generate, find insufficient saved evidence, or find that its
sources changed during generation. On iPhone, **Check again** refreshes model
availability. [Search](/search#ask-cap) explains citations and source review.

### Can Spotlight or Siri search all my captured text?

The opt-in system index contains titles and manual tags, excluding source text,
notes, page bodies, OCR, and generated tags. It fails closed above 1,000 live
captures or when a complete valid snapshot cannot be built. In-app search still
reads the library. The named Shortcuts are **Find Captures**, **Open Capture**,
and **Draft Text**; they do not provide arbitrary Siri questions. Draft Text
requires review and Save. See [system discovery](/search#system-search-and-shortcuts).

## Background helper

### What is `capd-agent` in my login items?

It is Capd's background helper. It extracts readable page content, runs OCR and
on-device tagging, and generates website icons when enabled. In an enrolled
library it also runs sync. It can work while the menu-bar app is closed; available
model, network, and processing settings still apply.

### Captures are stuck in pending

Run `capd status` to check the queue and helper state. If the helper is missing or
stopped, `capd doctor` attempts to repair it. Processing is intentionally less
concurrent on battery power, so a large queue can take longer away from a
charger.

## Other

### Is there a configuration file?

Ordinary controls are in Settings or the shared database. Mac enrollment adds
`sync-configuration.json` with public connection identity; credentials remain
in Keychain. `CAPD_DIR` changes the Mac storage root and must match across the
app, Agent, and CLI. Deleting configuration does not safely disconnect a bound
library. See [Mac settings](/app) and [sync](/sync).

### Why isn't Capd in the Mac App Store?

Reading frontmost browser context requires capabilities unavailable inside the
Mac App Sandbox. Upstream provides direct downloads and Homebrew distribution.
Those artifacts do not establish installation or signing of this fork. Follow
the [fork installation guide](/install).

### My hotkey does not work

Another app or macOS may already own the shortcut. Open Settings and record a
new combination; the recorder warns about known system conflicts.
