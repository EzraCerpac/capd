## Your library, on Mac and iPhone

Capd saves the useful things you come across and helps you find them again.
The Mac app captures pages, selected text, links, notes and images. This fork adds
a local iPhone/iPad app and optional sync through a service you configure.

These pages describe [EzraCerpac/capd](https://github.com/EzraCerpac/capd), built on
[Jamie Davenport’s upstream Capd](https://github.com/jamiedavenport/capd). The
upstream website, releases, Homebrew cask and existing in-app update links
describe upstream. Follow this fork’s [installation guide](/install) for its
source build.

## Start locally

1. [Build and install the fork](/install), keeping the matching app, CLI and Agent together.
2. On the Mac, press **⌃⌥C** to capture, then **⌥⇧Space** to search.
3. On the phone, use **+** or the share extension to save a link or text.
4. Connect devices only when you have a prepared library service and device grant.

Captures are saved locally before sync. A closed-app phone share remains local
until the app can deliver it. Suspended iOS delivery is not guaranteed.

## Save, find and annotate

The Mac captures browser content, processes images with OCR and generates
on-device tags. The phone displays synchronized content, and lets you search,
edit notes/manual tags, review conflicts and delete a source.

Ask Cap provides local answers with supporting quotes and source links when
Apple’s on-device model is available. It has no remote model fallback. Optional
Spotlight and Shortcuts expose titles and manual tags; capture shortcuts still
require Save.

## Connect an existing service

The fork includes an authenticated library server and explicit device-connection
flows. Hosting, trusted HTTPS, device authorization and backups are separate
operator responsibilities. This is not automatic NAS discovery or shared-folder
sync.

[Connect devices and plan upgrades](/sync) · [Troubleshoot a connection](/troubleshooting)

## Icons without phone-to-website requests

**Load website icons** is off by default on the Mac. When enabled, an awake Mac
Agent generates icons for eligible links saved on connected devices, and sends
them through the existing library service. The phone displays locally cached
icons and never fetches website icons itself. Already cached icons work offline.
